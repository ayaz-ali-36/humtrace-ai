# Approved UI Baseline

Status: **Approved and fixed**
Approved by: Project owner
Approval date: 2026-08-19

## Authority

The interface currently implemented in `web/` is the authoritative HumTrace design. It replaces all earlier concepts and reference designs. Future work must preserve this baseline unless the project owner explicitly requests a redesign.

## Design to preserve

- Clean white and soft-mint visual system with dark navy text and restrained green accents.
- Simple HumTrace branding and compact navigation.
- Home, Search, Browse, Report Missing, and Report Unidentified navigation.
- A visible `My Dashboard` destination for signed-in reporters.
- A compact signed-in account control that reveals the reporter name and sign-out action.
- The current split home-page hero with concise copy, clear report actions, and the face-pattern scanner illustration.
- Human-readable language, short content, generous spacing, rounded controls, and minimal visual clutter.
- The current responsive mobile navigation, with links shown clearly without overlapping page content.
- Report photographs fitted cleanly within their cards without distortion.

## Change policy

Allowed without redesign approval:

- Bug fixes, accessibility improvements, responsive corrections, and performance improvements.
- Small copy corrections that do not add unnecessary text.
- Fixes required to keep an existing workflow functional.

Requires explicit project-owner approval:

- Changing the color system, typography direction, page composition, navigation model, hero design, or visual identity.
- Restoring an older generated design or any deleted reference layout.
- Adding decorative sections, large amounts of explanatory copy, or unrelated features.

When a future task is ambiguous, preserve the current appearance and make the smallest necessary change.
